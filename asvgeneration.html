ASV generation

We recommend using the Apscale pipeline for the generation of ASV tables, which can be either executed in the cloud via CloWM, or locally via command line.

The Apscale pipeline handles the following steps for the generation of ASV tables:

  • Paired-end merging - merges corresponding forward and reverse reads into one sequence, with thresholds for maximum difference percentage, maximum nucleotide differences, and minimal overlap between forward and reverse reads.
  • Primer trimming - the removal of the sequencing primers
  • Quality filtering - with thresholds for maximum expected errors, and length of the resulting sequences
  • Dereplication
  • Denoising / Swarm clustering - with thresholds for strictness to delineate between artifacts and real biological sequences
  • Replicate merging
  • Removal of negative controls
  • generation of ASV tables - with the possibility to set a threshold for OTU generation

Apscale is provided as a workflow on the Cloud-based Workflow Manager platform (CloWM). After registration, Apscale can be chosen from the list of available workflows, raw files can be uploaded, and options can be set for the execution of the workflow.

For users, who want to run Apscale locally, the latest version of the pipeline is available from GitHub.

For more details on the different options of the pipeline, please refer to the official manual.
