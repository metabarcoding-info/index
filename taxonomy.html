Taxonomy assignment

Assignment of taxonomic information to the generated ASV sequences is highly dependent on the taxonomic scope of the project. General all-purpose archives provide a broad range of taxa, while local databases, or references with a narrow taxonomic scope can be more helpful for more specific research questions.

It is possible to upload ASV tables to the ASV Registry. There the sequences can be blasted against the available reference databases (from there, the publication process via the ASV Registry can easily be started).

The BOLD reference libraries represents a large amount of marker-specific libraries, especially COI sequences. The BOLD Identification Engine can either be accessed directly on the site, or via algorithms such as BOLDigger3, which provides additional functionalities and user comfort.

For a more regional scope, the identification engine from the German Barcode of Life (GBOL) can be used in the same way as the global BOLD database.

Custom references

Reference databases fro Metabarcoding analyses usually are one of two ends of the spectrum: they are either well curated databases with high quality sequences, that have a very narrow taxonomic scope, or they are generated from the enormus amount of available sequences from public repositories. In the latter case, it can be challenging to identify bad quality sequences, that are wrongly annotated.

We think, that the wealth of different sequences and sequence variants from the same species can outweigh the high quality curated databases with a smaller scope (especially for work with plant sequences). To that end we have developed a method for the generation of custom reference databases, which focuses on the primer sequences used during the amplification of the samples and involves a method for retaining high quality sequences in the reference database.

The R- and Python scripts used for the generation of such custom reference databases can be found in its GitHub repository, along with the example of the generation of a reference database for the ITS2 marker with the primers ITS-3p62plF1 and ITS-4unR1. We plan to update this repository with further reference databases for frequenctly used primer combinations for ITS and COI markers.

Furthermore, we developed an analysis script, which takes the quality score from the custom reference databases into account to identify the most likely high quality reference for a given ASV, and can perform a check against GBIF occurrences to see how likely it is that a given species was identified in the study area. With the incorporation of local occurrences for the complete database (see the database generation repository for details), the custom reference databases, can also be used as a local database, without excluding non-native species from the database completely. The Analysis script MEAN-CURE (MEtabarcoding ANalysis with a CUstom REference) can be found on its GitHub repository.
